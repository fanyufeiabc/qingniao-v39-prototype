# 青鸟 V9.2.0 深度核对、整改及交付报告

版本日期：2026-10-12（北京时间）。基线：V9.1.2-W8R2B-C1 / 原型main 4a29e46456453006c6cf82b0305853ca0c65aa0e。

## 核对结论

原设计有偏差，不能认定已全部满足。V9.2.0修复了Cookie明确入口、店铺独立管理后台地址、平台/账号/店铺配置停用及门禁；补充PC与UTP授权的区别和完整业务操作提示。扫码与账号密码由本人在固定PC平台网页完成，验证码及风控由本人处理。Cookie可复用独立档案或在本机高级导入，不传NAS，不因导入而直接核定身份。

已有商品、草稿、订单、采购、物流、售后和费用业务、本人关键确认及UNKNOWN锁保留。设计支持、源码实现、本地测试与真实平台证据分别登记。所有平台全功能真实验收、全系统逐页收口、普通用户独立上手均尚未完成。

## 登录、配置及PC连接核对

| 场景 | 当前设计与实现 | 验证边界 |
| --- | --- | --- |
| 平台新增编辑与扩展 | 资料、账号及店铺分开；平台标识/用途固定；新增只登记，适配未开发 | 本地保存回读、重复、版本、非法输入回归；拼多多批发未新增适配 |
| 多账号与档案 | 同平台可有多个本人账号；每账号固定PC独立档案和目录 | 模拟档案隔离回归；实机多档案待SIT |
| 店铺后台地址 | 本人维护managementUrl，优先于平台loginUrl；未配置地址阻断 | 请求冻结网址、方式、版本和设备；不猜平台官网 |
| 扫码 | 在平台页面由本人扫码；支持程度取决于实际平台页面 | 入口/编排实现，不代表每平台扫码已实测 |
| 账号密码 | 本人在平台网页输入密码和验证码；青鸟没有密码配置字段 | 入口/编排实现，不承诺自动填密码或自动验证码 |
| Cookie | 独立档案复用；高级JSON本机导入，校验域名、期限、重复与格式 | 本地模拟导入通过；域名通用性、平台失效和重启复用待实样 |
| 本人核对 | PC回传观察，NAS本人确认账号/店铺编号；错身份不更改绑定 | 人工观察与确认实现；平台自动提取身份尚未统一完成 |
| 会话有效期 | 15分钟请求、30分钟身份核对窗口；不等于平台Cookie寿命 | 过期/撤销/错档案/版本变化阻断；业务适配仍需当前身份核验 |
| PC连接 | 配对、心跳、Windows交互、Agent运行、身份及业务能力分别判断 | 本机控制台来自固定PC；原型不连接真实PC |
| UTP授权 | UTP session_status与PC浏览器Cookie分离；按具体能力核验 | Login/Link关系待SIT；不把扫码或linked=false硬套所有只读能力 |
| 停用与改绑 | 配置启停区别于业务适配开关；任务或UNKNOWN锁阻断危险变更 | 待登录取消、身份失效、禁领取；历史订单不删，重启配置重新核对 |

## 额外纳入的核对事项

金额用最小货币单位及明确币种，空值与零分开；数量及计量单位、整单费用、运费和退款归属不能推断。统一北京时间业务日期与增量边界，订单分页重叠去重。图片来源、授权及主图详情图、包装原图、类目字典版本均保留证据。袜子内衣商品材质、成分、尺码、SKU变体和平台审核字段在真实准备样本时核对。

系统只允许本人经营，PC只执行授权任务。接口保留会话/CSRF、幂等、版本和确认快照，设备撤销、租约超时、无交互会话、重复回执、跨平台对象及结果未知均有相应测试族。升级不改V001–V037原SQL，仅V038；已有数据库先备份、账本校验和开发隔离库迁移。卸载/升级保留本人配置与档案，不自动启动经营服务。Windows安装器构建和实机运行分开登记。

## 普通用户易用性及实际整改

| 问题 | V9.2.0整改 | 剩余工作 |
| --- | --- | --- |
| 不知道先配置什么 | 统一入口五页签，名称/账号/我的店铺及下一步分清 | 首次配置逐步向导与真人耗时测量 |
| 以为PC在线就是平台能用 | 显示真实设备心跳及交互条件，展开连接要求 | 实机各状态联动与误操作率验证 |

| 找不到店铺后台地址 | 我的店铺新增编辑及列表可见管理后台网址 | 实平台跳转登录回读验证 |
| 不知道业务下一步 | 采集/商品/草稿/订单/采购/物流/售后页补折叠操作顺序和验证范围 | 实际所有业务页逐项按钮/字段收口 |

扫码、验证码、身份确认、支付及退款人工操作是明确业务边界；可通过分步引导、平台身份自动读取和回读展示简化，但不能删除关键确认、商品明细关联或未知结果对账。原型较通俗，实际系统的67条历史路由差异和部分通用表单仍需继续收口。
