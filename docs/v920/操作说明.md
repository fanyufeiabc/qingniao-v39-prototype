# 青鸟 V9.2.0 配置登录与业务操作说明

1. 在平台与账号设置新增或编辑货源/店铺平台名称、官网和登录网址。资料配置不等于业务适配可用。
2. 为每个平台新增本人账号，选扫码、本人输入账号密码、手工登录或本机Cookie登录状态。密码和验证码只输入平台网页。
3. 每个账号创建独立浏览器档案，在PC执行设备中配对固定PC。一次性资料填到本机控制台，指定Chrome/UTP程序和不同档案目录。
4. 在我的店铺绑定同销售平台账号，维护店铺管理后台网址。本人发起登录时先打开店铺后台；未配置则用平台登录网址，二者都缺则阻断。
5. 在固定PC停止Agent后读取待登录请求，打开本任务的独立平台网页。扫码/账号密码在平台网页进行。已有档案状态可以复用。
6. Cookie高级导入只在本机控制台：打开Cookie登录任务后选择JSON文件，勾选本人确认。格式为Cookie数组或含cookies数组的对象，每项包含name/value/domain/path/expires/httpOnly/secure/sameSite；expires=-1为会话Cookie，secure必须true，sameSite取Strict/Lax/None。不支持直接粘贴任意HTTP Cookie头或导入其他账号/平台文件。
7. Cookie导入后仍核对页面账号及店铺编号。PC填写编号和本机记录引用，回传观察；回到NAS本人逐项确认。原型模拟不上传真实密码、Cookie或验证码。
8. 验证码、风控和登录过期本人在固定PC处理；重新核对身份。PC连接、Windows解锁、平台会话、身份核对和业务适配分别检查。30分钟身份核对窗口不代表Cookie有效期。
9. 关闭登录浏览器后本人启动Agent。找货采集及每个平台业务按已核验能力执行。1688 UTP授权独立于浏览器，未验证的能力不放行。
10. 编辑商品和包装字段先核对证据并保存回读，商品草稿同步回读后本人确认发布。订单回流按商品明细采购，本人确认建单，支付到外部平台完成。物流按明细关联采购包裹并确认同步。售后本人关联多采购单，退款手工分配。
11. 结果未知不重复提交，回异常中心只读对账；原确认和锁保留。重复配置、版本冲突、身份不匹配及回读失败保留输入，先核查再重试。
12. 停用配置前处理活动任务或锁，停用不删除数据；重新启用须再核对。升级NAS/PC同时使用9.2.0，现库先备份后在隔离开发库核验V038，生产部署统一SIT。
