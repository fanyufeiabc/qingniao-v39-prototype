# V9.2.1-R1 路由、授权入口与页面收口

本增量保持产品版本 V9.2.1，承接上一交付，不覆盖 V9.2.0 和 V9.2.1 历史测试、需求与交付文件。经营方式、本人确认及真实环境后置口径不变。

## 需求与设计

1. 历史场景应定位到对应业务页。67 条旧映射由过宽的模块首页改为原型已经逐场景审定的目标；165 个历史场景、61 个逻辑页面和18个菜单均保留。旧差异清单作为历史记录不删除。路由对齐不代表历史页面所有字段和动作已经承接。
2. 标签切换保留商品、店铺、账号、档案、任务、对象版本、筛选和原列表返回位置。解析白名单不包含密码、原始 Cookie 或令牌。`legacyPageId` 仅为前端追踪信息，不增加业务 DTO 字段、不授予权限。
3. 旧 PC 编号只映射一次；标准化后保留历史来源，跳到新的当前页面时不再次解释旧编号。跨 NAS/PC 端的错误路径显示未找到页面，不落到其他业务页。
4. UTP 管理 SYS-005 使用既有独立授权组件：GET `/configuration` 取得本人账号与已配对档案，GET `/utp-authorization` 取得绑定及请求，再沿用已审定授权接口。配置、请求、回读、本人确认、取消和停用均保留原版本、身份及业务准入校验。打开页面仅只读，不自动授权、不自动登录或重发任务。
5. 所有动态业务表格放入可键盘聚焦的横向滚动容器，保留各列、表单输入及按钮；不通过删除列或整体隐藏溢出来通过检查。
6. NAS 小屏显示“打开全部菜单”，展开后可访问全部18个菜单；选择业务入口后收起。桌面保留常用12个及更多6个入口。PC菜单及实际业务确认不删除。

## 接口、ReadModel、数据库

本轮没有改变经营接口 DTO、ReadModel 数据形状和数据库迁移。V001–V039 原 SQL 保留。UTP管理页复用已经实现的授权与配置接口；本人扫码/平台密码/验证码仍在固定PC平台网页完成，NAS不增加平台密码或原始Cookie功能。前端路由不是身份凭据，后端仍核对本人、店铺、账号、对象版本及原锁。

## 页面验收解释

四种宽度的渲染与页面标题、溢出检查覆盖NAS/PC全部61个逻辑页面和原型对应61页。商品/店铺使用隔离合成记录，部分列表为空，未配置图片存储、缺少采集任务等异常单独记录。页面标题和布局通过不等于全部查询、字段、按钮、对象定位及完整业务功能通过。人工视觉抽查与实际浏览器交互另列证据。

实际系统仍有独立页面/字段未实现或部分承接：经营核算总览、订单项核算、映射、存储、安全审计、AI配置、系统诊断、PC人工接管与任务监控等，逐页状态继续保持部分完成或未执行。不得因67条路由已经对齐而关闭这些功能。
