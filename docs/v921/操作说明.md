# 青鸟 V9.2.1 配置、授权及升级操作说明

1. 备份数据库、配置和媒体；停止NAS经营服务及PC Agent。NAS和PC同版升级，按安装向导核对账本并执行V039候选迁移，保留原独立浏览器目录。真实环境安装、数据库恢复仍在统一SIT验证。
2. 在平台与店铺设置登记平台、本人账号、固定PC档案和店铺。网页登录优先复用原独立档案；扫码、密码、验证码和风控只在PC平台网页完成。回传后在NAS本人核对，青鸟不接收平台密码或Cookie。
3. 为1688单独配置UTP Host、固定PC档案及已审定返回字段合同。高级字段映射须由开发/SIT按实际样本审定一次，普通使用无需每次填写。首次UTP买家编号可在授权回读后填写确认；已有采购历史应先核对原买家编号。
4. NAS发起“检查通道”“本人扫码授权”“本人网页授权”或“重新回读状态”。在固定PC停止Agent，进入登录中心的UTP区读取请求并执行。已核对的二维码或授权链接只在本机呈现；如果Runtime未返回可用呈现，不重复发起，先回读或取消后补合同。
5. 本机回读完成后，在NAS核对通道、linked和买家编号，勾选本人确认。未绑定买家可仅确认公开只读发现；采购、订单、采购物流和售后源侧仍要求买家身份及各自合同。不要把网页已登录、PC在线或扫码动作当成所有业务可用。
6. 结束本机授权操作后由本人启动Agent。Runtime切换账号、身份失效、请求过期或设备撤销会阻断。Cookie手工导入只在本机折叠高级区，不是默认必做步骤；导入后仍核对身份。
7. 有UNKNOWN时保留原确认与写锁，按原商品明细、金额、数量及外部编号只读对账。UTP未配置时可初次配置同一原档案；返回字段修正不得更换原账号/Host/PC绑定。旧写任务不会因新授权自动重发。发布、采购、物流关键确认和售后退款手工分配继续保留。

本版源码包括NAS/PC完整与独立包、原型、V039、安装/配置及需求文档。Node与Windows安装器以本版构建核验为准。Windows实机、目标PostgreSQL、真实平台整链与多宽度、真人上手尚未全量验收。
