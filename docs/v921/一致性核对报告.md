# V9.2.1 需求、设计、原型与源码一致性核对

本增量关闭UTP与网页登录混用的准入问题，保持个人/家庭作坊、唯一本人、固定PC执行场景。NAS没有新增平台密码、原始Cookie或Runtime会话令牌字段；数据库连接密码和青鸟本地登录密码属于原系统部署/访问凭据，不能混同为平台登录密码。

| 需求 | 对应实现与验证 | 判定 |
| --- | --- | --- |
| UTP与网页登录独立 | V039两表、三视图；Browser账号编号不被UTP首次绑定修改；网页登录发起/过期不撤销UTP | 本地实现及正反向测试通过 |
| NAS编排、固定PC执行 | 10条授权API、封闭DTO、独立设备/档案、请求15分钟、本人核对30分钟、MCP真实工具Schema检查 | 本地实现与模拟Runtime测试通过；真实返回字段待SIT |
| 普通用户复用Profile | 默认本人网页登录/已有档案复用；Cookie仅PC折叠高级选项 | 页面与接口保留，实机与平台Cookie样本待SIT |
| 授权失败、过期、身份变化、错设备 | 独立状态回读、版本和有效窗口检查、Runtime每次业务调用前校验；NAS/Runtime网络异常禁止写调用 | 16项专项通过，不等于真实平台授权成功 |
| 商品编辑完整性、旧版本阻断、包装人工核对 | W8R2B真实应用API与PGlite集成回归；完整隐藏字段/SKU/金额保留，旧版本412，逐包装字段人工确认 | 全量回归包含正反向及异常；原图与来源不覆盖 |
| 商品搜索→采集→落库→编辑→店铺草稿/发布 | W3/W3R2/W4/W5及微信/京东独立合同与执行器 | 本地回归通过，各平台能力和真实样本独立标记待SIT |
| 店铺订单→采购→物流 | W6/W6R2及微信/京东增量：来源、买家、金额、数量、运单、租约与本人确认 | 本地回归通过；平台外部建单/物流不宣称实测 |
| 售后双侧关联、费用与退款核对 | W6R3/W7R5/W7R10；本人按商品明细关联多张采购单，退款手工分配，两侧上限分别校验 | 本地回归通过；不自动退款、支付或裁决 |
| UNKNOWN锁定与恢复 | 保留原写锁，只读对账；旧任务缺新授权快照不能自动重发；固定身份不变可修正字段合同 | 本地反向测试通过，真实UNKNOWN样本待SIT |

61个逻辑页面、18菜单、181设计场景、历史2030字段/437按钮保留。全页核对JSON逐页承接V9.2.0状态，4个当前逻辑页及Browser区仅记本轮授权相关部分。67条详细路由差异仍开放，不能将本轮授权区测试标作全系统所有字段、按钮、查询和响应式收口。

历史POC保留：用户2026-09-23报告1688独立Profile关闭重开仍登录；D01最新版商品ID与连续目录观察保留，MOQ/库存/SKU语义不扩大；S04已有订单只读不算新建采购单成功；小红书09-07C链接证据不算所有发布/订单整链成功，09-07D不同订单阻断不改为通过。历史UTP工具目录和扫码动作不算linked=true买家身份通过。UTP并行多买家会话仍待验证。
