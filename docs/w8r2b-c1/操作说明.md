# 青鸟基础配置操作说明

V9.1.2-W8R2B-C1

1. 打开“平台与账号设置”，选择货源或店铺平台资料，新增或编辑名称、官网、登录网址及接入方式。新平台业务适配显示待开发。
2. 切换对应账号页签，新增本人账号，选择登录方式；密码不在青鸟填写。
3. 为账号创建独立档案，进入“PC 执行设备”配对固定 PC，复制一次性配对资料到本机控制台，设置独立目录。
4. 对销售平台，在“我的店铺”新增店铺并绑定同平台账号。可先填写已知的外部编号，未知时登录后核对。
5. 在账号或店铺点击“登录并核对”，选择已配对档案。固定 PC 停止 Agent，读取待登录请求并打开独立平台网页。本人扫码或输入密码。
6. 在 PC 填写平台页面可见账号及店铺编号，填写本机核对记录编号，勾选本人确认并回传。回到 NAS 在“最近登录与身份核对”逐项输入相同编号并本人确认。
7. 刷新回读状态。已保存资料、已核对身份和业务适配可用是不同状态；身份过期后重新发起，UNKNOWN 锁仍先对账。

重复配置会阻断；旧版本不会覆盖新记录；保存失败或回读失败保留表单输入。修改登录网址、方式或身份会要求重新核对。已有订单或 UNKNOWN 的店铺不能换绑。

原型专用模拟工具仅演示回传和过期，不能代表真实平台已验证。纯 API 专有授权扩展及真实部署统一 SIT 后执行。
