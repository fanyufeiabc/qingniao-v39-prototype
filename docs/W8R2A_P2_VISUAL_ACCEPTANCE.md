## 正反向交互

商品编辑长表单、包装OCR逐项决定、售后错误行及负金额阻断、部分分配余额、错账号草稿回读阻断均已观察。本人确认未勾选时禁用执行，勾选后执行演示审核；Tab仍在弹窗内，Escape返回来源按钮。审核受理与在售状态分开。

UNKNOWN保留原确认、原版本及账号：错账号观察和证据回传均保持锁，裁决与重复写入禁用；可信观察回传仍保持原锁，NAS演示采纳后返回原对象，状态为审核中且无写锁。上述操作只使用静态演示数据，不执行真实外部写。

采购、物流、售后列表按钮实际点击后均进入对应详情并保留原订单上下文。验收中修复窄屏按钮逐字折行、宽表撑开卡片，以及三个列表按钮仅选对象但未进入详情的问题，并增加三个真实按钮路由测试。当前全量回归114组通过；生成文件6项可复现。
