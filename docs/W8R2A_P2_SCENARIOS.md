# 原型操作与正反向场景

先选择具体店铺和演示对象。页面刷新会重置本地演示状态；不请求 NAS、UTP、1688 或销售平台。

| 业务 | 正向操作 | 反向与结果 |
| --- | --- | --- |
| 商品与草稿 | 商品编辑保存→类目和七项条件分别核对→同步草稿→唯一完整回读→本人确认审核→审核回读→再次本人确认发布→在售回读 | 改价生成新版使旧草稿失效；缺任一条件、错账号、媒体身份缺失、多候选或内容不一致均禁止发布 |
| 本人确认 | 核对弹窗中的本笔店铺账号、商品规格、价格数量、地址/包裹、版本与摘要，勾选后执行演示 | 有未保存修改、快照变化、确认超过5分钟或模拟过期均拒绝执行 |
| UNKNOWN | 已确认请求→模拟结果不明→原快照只读对账→提交观察证据→NAS采纳可信结果 | 错账号、缺明细、多候选、错版本继续锁定；PC回传或重新登录不解锁 |
| 订单采购 | 按商品行关联1688来源SKU→生成两张采购草稿→补费用状态→核验报价→本人确认建单→精确回读 | 错规格、未知运费、负金额、币种不符、报价变化阻断；列表候选不是外部订单已确认；不执行支付 |
| 物流 | 同店同订单采购包裹→核对本批数量、运单、承运商映射与身份→本人确认→完整回读 | 空运单、零批次、超量、非整数、订单状态不符、冲突或UNKNOWN阻断 |
| 售后退款 | 每商品行本人选择同店同订单采购单→手工填两侧金额→保存部分或完整分配→修订/冲销 | 无对象、错商品行采购单、负数、超额、超过两位小数或币种不符拒绝；余额仍显示待分 |
| 批量采集 | 1–50条1688详情HTTPS链接→逐项检查→保序去重→模拟超时项单独重试 | 0或51条整批阻断；脚本URL、私网、错域、带凭证和异常端口逐项拒绝；成功任务不重复生成 |
| 包装OCR | 查看原图和文本框→生成候选→逐字段采纳或拒绝→部分回填新版本 | 52%低置信或冲突字段未人工核对不能采纳；来源商品版本变化需重新识别；包装图禁派生 |
| AI与媒体 | CLEAN/INSPECT分级建议→本人采纳新版本；授权质量通过后派生与采纳商品图 | 建议不自动覆盖商品；模糊、无授权或包装图不派生；原件hash不变 |
| 财务 | 选择明确模拟核算场景→核对待补、估算及退款余额→全部实值和分配完成后展示结果 | 未知不置零，估算与部分分配不显示最终净利；外币凭证不直接合并CNY |
| PC | 未配对入口→一次性码→连接→启动/停止；登录完成后重新核验；原任务只读观察或步骤预演 | HTTP NAS地址、错/已用码、离线、协议不符、错卖家、过期会话、风控均阻断；执行步骤不替代NAS裁决 |
